# 50 IoT Penetration Testing Projects

A hands-on portfolio of authorized IoT and embedded-device security assessments, from lab setup and device discovery through firmware, wireless protocols, cloud integrations, detection engineering, and an end-to-end capstone.

**Safety:** Perform active testing only on owned devices, supplied training images, simulators, or systems explicitly authorized in writing. Keep labs isolated. Do not test live public infrastructure, medical devices, vehicles, safety-critical systems, or production OT. Use synthetic identities and data; avoid destructive changes, credential harvesting, persistence, and denial-of-service activity.

## Project format
Each project includes an objective, authorization and safety boundaries, prerequisites, lab preparation, a step-by-step workflow, tooling guidance, expected results, findings and risk guidance, remediation, validation, and deliverables. Each also includes three **simulated training illustrations** (baseline, findings, and validation); these are diagrams, not real screenshots or assessment evidence.
